# AGENTS.md

Personal NixOS flake config. Two hosts are declared in `flake.nix`:

- `desktop` — AMD/NVIDIA box, `hw_file = "nixos"`, rebuild with `.#desktop`
- `thinkpad` — Intel laptop, `hw_file = "thinkpad"`, rebuild with `.#thinkpad`

Flake attr name and `networking.hostName` differ for the desktop: the hostname is `nixos`, not `desktop`.

## Commands

- Rebuild/activate: `sudo nixos-rebuild switch --flake /etc/nixos#desktop` (or `#thinkpad`)
- Validate without activating: `sudo nixos-rebuild build --flake /etc/nixos#desktop`
- Update all inputs: `nix flake update`
- Format a file: `nixfmt <file>` (no configured lint/format/test task)

The repo lives in `/etc/nixos`, so rebuilds need `sudo`.

## Critical: flakes only see git-tracked files

New `.nix` files are invisible to `nixos-rebuild --flake` until they are `git add`ed.
Always stage new modules before rebuilding, or the change silently won't apply.

## Layout

- `configuration.nix` — shared NixOS entrypoint; imports `devices/${hw_file}.nix` plus `modules/*`.
- `modules/` — shared system modules; `modules/desktop/` are desktop-only.
- `devices/*.nix` — machine hardware config, auto-generated by `nixos-generate-config`. Do not edit.
- `home.nix` — home-manager entrypoint; imports `home-manager/*` conditionally on `device`.

## Device branching

- NixOS side: `hw_file` specialArg (`"nixos"` = desktop, `"thinkpad"` = laptop).
- Home-manager side: `device` extraSpecialArg, same values.
- thinkpad gets foot/fuzzel/firefox; desktop gets kitty/rofi/opencode/helium/games/wine.

## Gotchas

- `modules/desktop/cachykernel.nix` overrides the kernel from `configuration.nix` with
  `lib.mkForce` (CachyOS kernel on desktop).
- These files exist but are NOT imported — editing them has no effect:
  `modules/searxng.nix`, `modules/desktop/skwd.nix` (commented out in `flake.nix`),
  `home-manager/zsh.nix`, `home-manager/zathura.nix`.
- Desktop default session is Plasma 6 (`services.displayManager.defaultSession = "plasma"`);
  niri is enabled, hyprland/mango/river are disabled.
- `home-manager/opencode.nix` is desktop-only and only adds Cachix substituters.
